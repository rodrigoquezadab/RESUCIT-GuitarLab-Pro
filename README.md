# RESUCITÓ GuitarLab Pro

Plataforma interactiva para salmistas y guitarristas del Camino Neocatecumenal.

## 🎸 Características

- **Catálogo completo de 215 cantos oficiales** con letras y acordes en formato ChordPro.
- **Grabaciones oficiales en MP3** integradas para cada canto.
- **Cartillas originales escaneadas** en alta resolución (partituras y dibujos de Kiko Argüello).
- **Transposición cromática dinámica** en tiempo real (-1 / +1 semitonos).
- **Auto-Scroll manos libres** con 3 velocidades (1x, 2x, 3x).
- **Diccionario interactivo de acordes y tablaturas** con 3 modos de visualización:
  - 🎸 **Mástil (SVG)**: Diagrama de diapasón con digitación y notas.
  - 🎼 **TAB**: Tablatura de 6 cuerdas.
  - 📑 **Ambos**: Vista simultánea para máximo detalle.
- **Filtros por Etapa litúrgica** (Precatecumenado, Catecumenado, Elección, Liturgia) y por Tiempo/Momento.
- **Escuela de Rasgueos y Arpegios** con patrones rítmicos comentados.
- **100% Client-Side**: Funciona en cualquier navegador moderno sin backend, listo para GitHub Pages.
